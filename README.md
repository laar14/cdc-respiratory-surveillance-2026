# NHSN Respiratory Admissions
Data project analyzing weekly hospital respiratory admission levels from NHSN.
This repository contains weekly respiratory admission data reported to the National Healthcare Safety Network (NHSN). The dataset includes confirmed COVID‑19, Influenza, and RSV hospital admissions across U.S. states and territories, along with per‑100k population rates and reporting completeness.

The goal of this project is to provide a clean, accessible dataset for:

Public health surveillance

Trend analysis

ETL and data‑quality demonstrations

Exploratory data analysis (EDA)

Visualization and reporting

Machine‑learning forecasting (optional future work)
